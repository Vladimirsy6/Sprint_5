# UI-автоматизация для учебного сервиса «Доска»

## Описание проекта

В этом проекте реализованы UI-автоматизированные тесты для учебного сервиса «Доска» — специального сайта, разработанного для студентов и практики в тестировании.

Цель проекта — покрыть автотестами основные пользовательские сценарии по регистрации, авторизации, выходу из системы и созданию объявлений.

## Используемые технологии

- Python 3.x
- Selenium WebDriver
- Pytest
- Google Chrome (браузер для запуска тестов)

## Структура проекта

- `tests/` — директория с тестами, разбитыми по функциональным модулям и классам
- `Sprint_5/locators/locators.py` — модуль с описанием локаторов элементов страницы
- `Sprint_5/conftest.py` — фикстуры для настройки и закрытия WebDriver
- `README.md` — описание проекта
- `.gitignore` — файлы и папки, исключённые из контроля версий

## Описание тестируемого функционала

### Регистрация пользователя
- Регистрация нового пользователя с генерацией уникального email
- Проверка валидации email (некорректный формат)
- Проверка регистрации с уже существующим email и отображение ошибок

### Логин пользователя
- Вход в систему с валидными данными
- Проверка отображения аватара и имени пользователя после входа

### Логаут пользователя
- Выход из системы
- Проверка скрытия данных пользователя и появления кнопки входа

### Создание объявления
- Попытка создания объявления без авторизации (появление модального окна с просьбой авторизоваться)
- Создание объявления авторизованным пользователем: заполнение всех полей, выбор категории, города и состояния товара, публикация объявления
- Проверка отображения созданного объявления в профиле пользователя

## Важные особенности

- Для регистрации в каждом тесте используется **уникальный email, генерируемый динамически**.
- Все тесты полностью **независимы и автономны** (инициализация и завершение WebDriver выполняется через фикстуры).
- В тестах **отсутствуют принты, слипы и неявные ожидания**, используется только **явное ожидание элементов через WebDriverWait**.
- Каждый тест завершается `assert` с проверкой ожидаемого результата.
